# Mini 2D RPG Prototype

This is a compact single-player 2D RPG prototype implemented in Python using Pygame.

Quick start (Windows):

1. Create a virtualenv and activate it.
2. Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

3. Run:

```powershell
python start.py
```

Controls:
- Arrow keys / WASD: move
- `S`: save game
- `L`: load game
- `I`: show inventory
- `Esc`: quit

This is intentionally a compact prototype; feel free to ask to expand features.
